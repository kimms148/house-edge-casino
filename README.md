# 하우스 엣지 — 교육용 모의 카지노

온라인 도박의 위험성을 보여 주기 위한 모의 카지노입니다. **가상 포인트만 쓰며 현금 가치가 없습니다.**

- 게임 8종: 동전 뒤집기, 가위바위보, 경마, 달팽이 경주, 홀짝, 바카라, 슬롯머신, 그래프(크래시)
- 기록 화면(게임별 판 수·승률·누적 손익 그래프), 키 설정(키보드 + 마우스 버튼)
- 관리자 콘솔: 접속자의 포인트와 진행 중인 판을 실시간으로 보고, 전체·게임별·개인별 확률 조작, 진행 중인 판 뒤집기, 미끼 모드, 니어미스, 폭로 모드

## 실행

```bash
npm install
ADMIN_PASSWORD=원하는비밀번호 npm start
```

http://localhost:3000 에 접속한 뒤 로비 아래 **관리자 로그인**에 비밀번호를 넣으면 관리자 탭이 열립니다.

## Render 배포

저장소에 `render.yaml`이 있으므로 Render에서 **New → Blueprint**로 이 저장소를 고르면 됩니다.
`ADMIN_PASSWORD`는 Render가 자동으로 만들며, 대시보드의 서비스 → Environment에서 확인·변경할 수 있습니다.

- 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 접속 때 깨어나는 데 30초~1분 걸립니다.
- 확률 설정은 서버 메모리에만 있어 서버가 재시작되면 초기화됩니다. 플레이어 포인트와 기록은 각자의 브라우저(localStorage)에 남습니다.

도박 문제 상담: 한국도박문제예방치유원 헬프라인 **1336** (24시간)
