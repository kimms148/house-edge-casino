# 하우스 엣지 — 교육용 모의 카지노

온라인 도박의 위험성을 보여 주기 위한 모의 카지노입니다. **가상 포인트만 쓰며 현금 가치가 없습니다.**

- 회원가입: 학번(5자리) · 이름 · 비밀번호. 학번 `20319` = 2학년 3반 19번 (반 1~7, 번호 1~19)
- 게임 8종, 기록 화면, 반별 수익률 랭킹, 건의함
- 관리자(아이디 `manager`): 학생 자산·진행 중인 판 실시간 관찰, 확률 조작, 자산 지급·회수, 비밀번호 변경, 우편함

## 실행

```bash
npm install
npm start
```

http://localhost:3000 — DB 설정이 없으면 `data/db.json` 파일에 저장합니다.

화면 코드는 `src/`에 나뉘어 있고 `npm run build`로 `public/app.html`을 만듭니다.

## 환경 변수

| 이름 | 설명 |
| --- | --- |
| `DATABASE_URL` | Postgres 연결 주소 (Render에서는 자동 연결) |
| `MANAGER_ID` / `MANAGER_PW` | 관리자 아이디·비밀번호 (기본값 `manager` / `manager`) |

## Render 배포

`render.yaml` Blueprint가 웹 서비스와 무료 Postgres를 함께 만듭니다.
무료 Postgres는 생성 후 30일이 지나면 만료되므로 그 전에 데이터를 백업하거나 유료로 바꿔야 합니다.

배포하면 설치한 앱도 다음에 열거나 화면으로 돌아올 때 자동으로 새 버전을 받습니다.

도박 문제 상담: 한국도박문제예방치유원 헬프라인 **1336** (24시간)
